# SchizoCheck — Interactive Demo (Static Port)

A front-end JavaScript port of the **SchizoCheck** expert system (originally Laravel 11),
built so the screening demo can run anywhere as a static site — the Certainty Factor +
Forward Chaining engine runs entirely in the visitor's browser.

- Live demo: https://portofolio-hasbi.web.id/schizocheck-demo/
- Original application (Laravel): https://github.com/Hasbi1605/ES-Skizofrenia

The knowledge base (30 symptoms, 5 diagnoses, 47 expert rules) and the CF computation
are identical to the server version — verified against the original logic on 300
randomized answer sets with zero mismatches.

Files in `docs/` (GitHub Pages source): `index.html`, `style.css`, `data.js`, `app.js`.
